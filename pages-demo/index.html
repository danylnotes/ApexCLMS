An enterprise learning, competency and career-development platform for an oil and gas organisation. Choose a fictional employee, manager or administrator to explore the platform as they see it.

This is a static, read-only demonstration. GitHub Pages can only serve static files, so each page here is a snapshot captured from the running application for that person. You can browse dashboards, courses, CPD, competencies, plans, reports and administration screens. Saving, enrolling, submitting and approving require the full application (Next.js and PostgreSQL) — see the source and setup guide.
